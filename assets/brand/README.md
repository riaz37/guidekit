# GuideKit brand assets

Source-of-truth SVG files for logos, favicons, and social previews.

## Brand tokens

| Token | Value | Usage |
|-------|-------|--------|
| Primary | `#6366f1` | Buttons, FAB, badges, OG gradient |
| Primary dark | `#4f46e5` | Gradient end, hover |
| Text | `#0f172a` | Wordmark on light backgrounds |
| Background dark | `#0f172a` | OG card background |
| Background light | `#ffffff` | Docs, README |

Font stack: `system-ui, -apple-system, Segoe UI, Roboto, sans-serif`

## Files

| File | Purpose |
|------|---------|
| `logo.svg` | Square icon mark (512×512 viewBox). Widget FAB sparkle on indigo rounded square. |
| `wordmark.svg` | Icon + "GuideKit" for navbar and README headers. |

## Where assets are used

- **Docs site** — `apps/docs/public/logo.svg`, dynamic `app/icon.tsx`, `app/apple-icon.tsx`, `app/opengraph-image.tsx`
- **Example app** — `apps/example-nextjs/app/icon.tsx`
- **README** — `assets/brand/wordmark.svg` linked from root and package READMEs

## Repository

## Export sizes (when needed)

| Asset | Size | Notes |
|-------|------|-------|
| Favicon | 32×32 | Generated by Next.js `app/icon.tsx` |
| Apple touch | 180×180 | Generated by `app/apple-icon.tsx` |
| OG / Twitter | 1200×630 | Generated by `app/opengraph-image.tsx` |
| PWA | 192, 512 | Referenced in `site.webmanifest` via `/icon` routes |
| GitHub social preview | 1280×640 | Upload PNG export to **GitHub → Settings → Social preview** |

To export a static OG PNG locally, run the docs app and open `/opengraph-image`, then save the image.

## Usage in markdown

```markdown
<p align="center">
  <img src="assets/brand/wordmark.svg" alt="GuideKit" width="200" />
</p>
```
